# Modern Firework PK Website

Made By NimbleVista 

A modern, futuristic redesign of fireworkpk.com featuring a clean white background with orange-to-red gradient accents.

## Features

- Responsive design that works on all devices
- Modern UI with smooth animations and transitions
- Multi-page structure with intuitive navigation
- Dynamic product displays with hover effects
- Clean and minimalist typography
- Optimized for performance and SEO

## Tech Stack

- Next.js - React framework for server-side rendering
- Tailwind CSS - Utility-first CSS framework
- Framer Motion - Animation library for React
- Responsive design for all devices

## Getting Started

First, install the dependencies:

```bash
npm install
# or
yarn install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Pages

- Home - Featured products and categories
- Products - Complete product catalog
- Categories - Browse products by category
- About Us - Company information
- Contact - Contact form and information

## Customizing

The theme colors can be customized in the `tailwind.config.js` file, which contains the custom color palette for the orange-to-red gradient theme.

## Deployment

The site is built with Next.js, making it easy to deploy on Vercel or any other hosting platform that supports Next.js applications.

```bash
npm run build
# or
yarn build
```
